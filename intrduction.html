Qu'est-ce que Git?

Git est un système de contrôle de version distribué utilisé pour suivre les modifications dans le code source pendant le développement logiciel.

Pourquoi utiliser Git?

  • Collaboration facilitée entre développeurs
  • Historique complet des modifications
  • Branchement et fusion efficaces
  • Gestion des versions

Comment installer Git?

  • Rendez-vous sur le site officiel de Git. Accés au site
  • Choisissez votre système puis suiver l'assitant d'installation
  • Vérifiez l'installation en ouvrant votre terminal et en tapant: 
    git --version
    pour vérifier l'installation si la version de Git s'affiche, l'installation est réussie.
