Workflow Git Simple

2. Développer sur la feature branch

Travaillez sur votre fonctionnalité sur cette branche. Commitez vos changements régulièrement :

git add .
git commit -m "Ajout de ma fonctionnalité"

3. Merge dans la branche principale via PR

Lorsque la feature est terminée, poussez la branche :

git push origin feature/ma-nouvelle-fonctionnalite

Puis ouvrez une Pull Request (PR) pour merger vos changements dans main ou develop.

4. Révision et validation

Un collègue revoit votre code, valide la PR et merge la branche.

5. Nettoyage

Après le merge, supprimez la feature branch locale et distante :

git branch -d feature/ma-nouvelle-fonctionnalite
git push origin --delete feature/ma-nouvelle-fonctionnalite
