Commandes Git essentielles

  • git init
  • git add
  • git commit
  • git status
  • git push
  • git pull
Commande Description
git init Initialise un dépôt
git add Ajoute les fichiers
git commit Enregistre les changements
git status Vérifie l’état
git push Envoie les modifications
git pull Récupère les modifications
